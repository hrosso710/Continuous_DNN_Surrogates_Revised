# Table/Figure Reproduction Overview

## Table 2 — relative error by architecture/depth/optimizer

Generated by: `matlab/experiments/run_all_table2.m` → `collectResults.m` → `results/table2_pivot.csv`

## Table 3 — DCR Hamiltonian, ΔError vs. Legendre degree (3–6)

Generated by: the `T=1` slice of the same degree-3–6 sweep used for Figures 4–5, restricted to DCR / Hamiltonian / ADAM. (Every `runConfigBatch` group includes the full degree sweep regardless of `T`; Table 3 specifically uses the `T=1` group.)

## Figures 2–3 — training/validation error curves (ResNet, Hamiltonian; ADAM; monomial vs. Legendre)

Generated by: `collectResults.m`'s tikz export (ADAM/sgd, `T=1` runs) → `results/tikzdata/*.dat`

## Figures 4–5 — validation error convergence across Legendre degree 3–6 (ResNet, Hamiltonian; all 3 datasets)

Same degree-3–6, `T=1` sweep as Table 3, spanning all three datasets and both architectures (Table 3 is the DCR/Hamiltonian slice of this same data). Generated the same way as Figures 2–3, filtered to the degree-sweep configs.

## Table 4 — neural ODE parameter count and test error by degree (stationary ODE task)

Generated by: `python/stationary_ode/ode_demo_NEW.py` via `run_experiment.sh` (degrees 3–5, monomial + Legendre, 5 seeds each — consolidated into one script, replacing the old separate degree-3 and degree-4/5 scripts) → `process_results.sh` → `aggregate_table4.py`. The static (identity) baseline is currently a hardcoded, unconfirmed value (`8.2132`) — `run_experiment.sh` doesn't yet run `basis='none'` to regenerate it; see `python/README.md`'s Status section for the full note.

## Table 5 — neural ODE train/val error, surrogate examples (ELM, CDR, DCR)

Generated by: `python/surrogate/train_surrogate_node.py` → `python/surrogate/run_experiment.sh` → `process_results.sh` → `aggregate_table5.py`. This pipeline's exact protocol (degree=3, 5 seeds) is flagged as an unconfirmed assumption in `run_experiment.sh`'s own comments, not yet checked against a manuscript draft of Table 5.

## Table 6 — neural ODE train/val/test error, stationary ODE task

Generated by: the same pipeline as Table 4 (`python/stationary_ode/ode_demo_NEW.py`), degree-3-only slice, 5 seeds → `aggregate_table6.py` (kept as a separate script from `aggregate_table4.py` rather than folded in). Shares Table 4's static-baseline gap for the `basis='none'` row. See `python/README.md`'s "Train / validation / test split" section for the reporting convention shared across both tables.

## Figure 6 — neural ODE loss vs. function evaluations, surrogate examples (ELM, CDR, DCR)

Generated by: `python/surrogate/train_surrogate_node.py` — same source as Table 5, **not** `ode_demo_NEW.py` (which only covers the stationary/synthetic ODE task used for Tables 4 and 6).
