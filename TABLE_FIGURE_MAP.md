# Table/Figure Reproduction Overview

## Figures 2–6 — caption fix (validation, not testing, error)

Figures 2, 3, 4, 5, and 6 were captioned "testing error/loss" in earlier drafts, but this was a proofreading inconsistency. The ADAM solver's per-iteration training history only logs **train** and **validation** loss — test error is computed once, as a final scalar, after training completes, so there was never per-iteration test error to plot. Per referee comment 2.6.5 (reserve validation error for iteration-indexed training plots, test error for final summary tables/comparisons), the captions now correctly read "validation error." **Captions fixed** in `main_new.tex`; no code or data change was needed.
